# 烟蒂池设计草案（2026-10-07，待裁定）

> 应用户问题而作：没有显著护城河、不在关注池的公司，能否仍符合烟蒂股标准；若可能，建一个独立于关注池的烟蒂池，用来记录和分析值得关注的烟蒂股。本文只给标准与结构，口径和阈值由用户裁定后才写入工作流程。全市场粗筛的脚本与读数见 `data/experiments/exp_cigar_butt_design_20261007/`，跟踪项为 OI-273。

## 一、结论

1. **可以。** 关注池（工作流程 §5）判断的是优势能否持续，烟蒂判断的是现在拿到的资产值多少。烟蒂的安全边际来自价格与保守清算价值（或可分配现金）之间的差距，不依赖未来复利，所以护城河不是前提。
2. **两者赚钱的机制相反。** 好公司的时间是朋友，烟蒂的时间是敌人：平庸生意的资产会被经营亏损、低效再投资和大股东侵占慢慢吃掉。烟蒂池的标准因此要管住三件事：资产是否真实可变现；价值流失得多快；价值靠什么兑现。
3. **A 股的现实（2026-06-30 半年报、09-30 收盘粗筛）：**
   - 经典的净流动资产型（市值低于保守净营运资金）为 0 家，最接近的十几家市值是保守净营运资金的 1.5～2.3 倍。
   - 市净率 ≤ 0.5 的非金融股 35 家（含 6 家 ST），集中在地产、钢铁、水泥、基建。
   - 市净率 ≤ 0.5 的银行 16 家，平安银行 0.48 排第 14 低。
   
   A 股的烟蒂机会主要不是格雷厄姆的净流动资产型，而是资产折价型和低市净率金融型。这两类的价值陷阱风险更高，排雷要更严。
4. **建议先只做研究观察池**：不进 §9.3、不产生交易、不占账户额度。积累一到两个报告季的记录和历史检验后，再决定要不要设独立的交易仓位。

## 二、定位与边界

- **入池对象**：A 股中不在 `worth_attention` 的公司，包括 `boundary_pending`、`documented_not_attention` 和未初筛者。
  - 关注池成员不重复入池，它们已由主模型估值。
  - `garbage` 一律不入（现有 12 家，子类多为「多年掏空／结构性绝望行业」）。
  - ST、*ST 不入。
  - 港股留作第二阶段（H 股折价、净现金小盘股更常见）。
- **烟蒂价值 `V_cb`**：只用资产负债表和已实现的现金分配，不用增长假设。与 §6 生产模型、§6.9 独立估值分开，烟蒂 `P/V` 写作 `P/V_cb`，不与模型 `P/V` 混用。重点级公司入池前须做一次 §6.9 独立估值作对照。
- **与关注池的关系**：入池不改 `attention_class`。公司若经 §5 复核进入 `worth_attention`，即移出烟蒂池。

## 三、四类烟蒂与烟蒂价值

| 类 | 适用 | `V_cb`（每股，普通股口径） | 重点级门槛 | 兑现退出 |
| --- | --- | --- | --- | --- |
| A 净流动资产型 | 非金融 | 保守净营运资金：调整后现金 + 交易性金融资产 × 0.9 + 应收票据与应收款项融资 × 0.9 + 应收账款（净）× 0.75 + 存货 × 0.5 + 合同资产 × 0.5 + 预付与其他流动资产 × 0.25 − 全部负债 − 少数股东权益 − 其他权益工具 | `P/V_cb ≤ 0.8` | `P/V_cb ≥ 1.0` |
| B 净现金加盈利型 | 非金融，近五年税后经营利润均为正 | 调整后净现金 + 5 × min(近五年税后经营利润中位, 最近一年) | `P/V_cb ≤ 0.8` | `P/V_cb ≥ 1.0` |
| C 资产折价型 | 非金融，主要资产可核实 | 可变现净资产，按下表逐项折扣 | `P/V_cb ≤ 0.7` | `P/V_cb ≥ 1.0` |
| D 低市净率金融型 | 银行（保险、券商另议） | 压力后普通股 BVPS × min(1, (可持续 ROE − 3%) ÷ (COE − 3%)) | `P/V_cb ≤ 0.75`，且过第四节第 7 条 | `P/V_cb ≥ 1.0` |

- **调整后现金** = 货币资金 − 受限资金 − 客户资金。存放于关联财务公司的部分按 50% 计。
- **调整后净现金** = 调整后现金 + 交易性金融资产 − 有息负债 − 租赁负债 − 其他权益工具（永续债、优先股）。

**C 类折扣表**（逐项写依据，资产负债表日为最近一期定期报告）：

| 资产 | 计入比例 |
| --- | --- |
| 调整后现金、交易性金融资产 | 100%、90% |
| 上市公司股权 | 市值 × 70%（含税与流动性折价） |
| 非上市股权、长期股权投资 | 账面 × 30% |
| 投资性房地产 | 公允价值 × 60%；成本计量的账面 × 50% |
| 应收账款 | 75%；政府与平台类 50% |
| 存货 | 商品类 50%；在建或未售开发物业 50%；已完工开发产品 60% |
| 合同资产 | 50% |
| 固定资产、在建工程 | 0～40%：专用设备 0，可单独变卖的不动产 20%～40% |
| 商誉、无形资产、递延所得税资产 | 0 |
| 全部负债（含预收与合同负债）、少数股东权益、其他权益工具 | 按账面全额扣减 |

**D 类压力损失**：

- 额外损失 = max(0, 不良贷款 × 60% + 关注类贷款 × 25% + 仍列正常类的重组贷款 × 10% + 正常类贷款一年预期损失 − 贷款损失准备) × (1 − 25%)。
  - 正常类一年预期损失按对公 0.35%、按揭 0.15%、信用卡 5%、其他零售 2.5% 计。
  - 准备同时覆盖正常类贷款，只拿不良和关注去比准备会高估富余。零售占比高的银行差别尤其大：平安银行按只比不良和关注的口径算，准备富余 300 多亿元；计入正常类后缺口 90 亿元。
- 压力后普通股 BVPS = (归母权益 − 其他权益工具 − 已宣派未除息股利 − 额外损失) ÷ 普通股数。
- 可持续 ROE 先剔除非信贷减值转回、资产处置收益等一次性项目，再取近三年 ROE 与最近四个季度年化 ROE 的较低者。
- COE 按银行类别取值：国有大行 10%，股份行 11%，城农商行 11%～12%。

## 四、排雷闸门（任一条不过即退回，记原因）

1. **治理**：近三年有非标审计意见、证监会立案或信息披露违法处罚、控股股东资金占用或违规担保未清，一律不入。
2. **退市风险**：股价低于 2 元；总市值低于 10 亿元；主板营收低于 3 亿元且最近年度亏损。
3. **现金真实性**（A、B、C 类）：利息收入 ÷ 平均货币资金低于 0.5%，或存贷双高（货币资金与有息负债都不低于总资产的 20%）。命中即退回，除非附注能逐项解释。
4. **价值流失**：近三年 `V_cb`（或普通股权益）年均下降超过 10%；或近三年经营现金流合计为负，且 `V_cb` ÷ 年均消耗不足 5 年。
5. **资本配置**：
   - 近三年单笔或累计超过净资产 20% 的现金并购；
   - 对关联方的大额委托贷款或理财；
   - 近三年以低于每股净资产的价格定增或配股（金融类同样适用）。
6. **流动性**：近 60 日日均成交额低于 1,000 万元的只记录，不进重点级。
7. **D 类另加**：
   - 核心一级资本充足率低于监管要求加 1.5 个百分点；
   - 拨备覆盖率低于 150%，或拨贷比低于 2%；
   - （不良 + 关注）÷ 贷款高于 5%；
   - 近三年 ROE 最低值低于 6%。

## 五、价值兑现路径（重点级至少一条，写进记录）

- **现金分配**：近三年平均分红率不低于 30%，或股息率不低于 4%，或正在执行回购注销。
- **资本运作**：资产处置、分拆、重组、要约收购或私有化，须已公告。
- **股东增持**：控股股东或管理层增持。
- **经营正常化**：周期底部回升，须写可证伪的里程碑和时点。

没有任何路径的公司留在观察级。

## 六、状态与节奏

| 状态 | 条件 |
| --- | --- |
| `candidate` | 粗筛命中，待逐家排雷 |
| `watch` | 排雷通过，但 `P/V_cb` 高于重点级门槛、缺兑现路径，或流动性不足 |
| `focus` | 排雷通过、`P/V_cb` 达门槛、有兑现路径、已做 §6.9 独立估值 |
| `exited` | `P/V_cb ≥ 1.0`（兑现）；闸门失效；或入池满三年未收敛（复核后默认退出） |
| `rejected` | 排雷不通过，记原因；12 个月内不重入，除非新报告推翻原因 |

- **全市场粗筛**：每个定期报告法定截止日后（4-30、8-31、10-31）各一次，用新报告期。
- **价格刷新**：每周一次，不进每日扫描。
- **逐家复核**：入重点级前做一次；之后每份定期报告后重算 `V_cb` 与闸门。
- **回顾**：每半年对已退出名单统计兑现率与收益，只作描述。

## 十、需要你裁定的事项

1. 是否建立烟蒂池（只研究、不交易）。
2. 四类是否都要；C 类与 D 类的价值陷阱风险最高，也可以先只做 A、B、D。
3. 门槛：重点级 A、B 类 0.8，C 类 0.7，D 类 0.75；兑现退出 1.0；满三年默认退出。
4. C 类折扣表与 D 类压力损失参数。
5. 第四节的排雷闸门，尤其是退市风险的市值与股价下限、现金真实性两条。
6. 港股是否纳入第二阶段。
