# OI-290 零增长下限检验：增长预测更准，估值准确性没有改善（2026-10-19）

用户 2026-10-19 裁定：g0 = 0 下限登记 OI-290 并检验，结果再裁定；按 §12.1（v4.254）以输入预测力与估值准确性裁定，回测收益读数只报不用。预登记与脚本见 `data/experiments/exp_oi290_20261019/`（[预登记](../../data/experiments/exp_oi290_20261019/preregister.md)），缘由见[增长率假设评估](growth_assumption_review_2026-10-19.zh.md)。本报告不改任何口径。

## 一、结论

**三个臂按预登记判定都是「部分支持」：只有输入预测力一项满足，两项估值准确性读数都不满足。**

- **输入预测力改善了**。受影响行改取 3%／5%／营收增速后，隐含增速离实际更近：
  - 净利增速绝对误差中位 0.204 → 0.176～0.186；
  - 营收增速 0.144 → 0.116～0.125。
- **估值准确性没有改善**：
  - 受影响月份的校准残差在对照臂已经含 0（3 年 −0.7%，5 年 +0.5%，年化对数），三个臂都没有改善；
  - 包含检验 λ 按 3 年回报显著为负（−8.5～−14.4），即调整方向与之后回报相反；按 5 年回报，FR 臂也为负，F3、F5 区间含 0；
  - 截面排序略变差：每月 `P/V` 与之后回报的秩相关，三个臂只有 18%～34% 的月份比对照臂好。
- **机会与陷阱**：机会捕捉率不变，买入区陷阱占比 −0.4pp [−0.7, −0.1]，踩中陷阱的段 −2.0pp [−4.0, −0.6]，改善很小。

**含义**：g0 = 0 的公司之后的利润确实比模型隐含的增长快，但在同样的 `P/V` 下，它们之后的回报并不更高，按 3 年口径还略低。可能的原因有两个：
- 这类公司多是窗口止于利润低谷，盈利锚已经按中位数把利润水平拉回，再加增长等于重复计算反弹；
- 市场已经为这些公司的增长定了价。

所以只把 0 下限抬高，增长读数更准，但不让 `P/V` 更准。

**建议**：三个臂都不采纳，研究开关保留、缺省关闭，OI-290 结案。逐家增长的问题留给 OI-291：独立审计按证据给增长路径，事前登记、事后记分，用实际成绩判断判断类增长是否比机械值准。

## 五、局限

- 「增量回报 ≤ 0」与「再投资率 ≤ 0」两类在本检验里合并成一组受影响行，没有分组报校准。
- 包含检验的 d 在受影响行内差异小，λ 主要识别「受影响组与其余公司在同一 `P/V` 下的回报差」，对小的组间差异放大明显。
- 校准与排序都是相对读数：只检验受影响公司相对其余公司是否被错估，不检验 `P/V` 的绝对水平。
