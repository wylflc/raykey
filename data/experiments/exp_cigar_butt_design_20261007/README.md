# 烟蒂池设计的全市场粗筛（2026-10-07，只读探针）

用户 2026-10-07 问：没有显著护城河、不在关注池的公司能否符合烟蒂股标准，并要求设计独立于关注池的烟蒂池。本目录只存设计用的粗筛读数，不进任何判定；设计见[报告](../../../docs/reports/cigar_butt_pool_design_2026-10-07.zh.md)。

```bash
python3 data/experiments/exp_cigar_butt_design_20261007/probe.py --report-date 2026-06-30 --raw <会话临时目录>   # 约 1 分钟
```

| 文件 | 内容 |
| --- | --- |
| `probe.py` | 东财数据中心 `RPT_DMSK_FN_BALANCE` 按报告期取全市场资产负债表（5,579 家），腾讯行情取收盘、总市值、市净率（5,551 只） |
| `probe_counts.json` | 各粗筛规则命中家数 |
| `probe_candidates.csv` | 命中名单：市值、市净率、保守净营运资金、现金减全部负债、名单分类 |
| `d_type_example.py` | 草案 D 类算例：平安银行压力后普通股 BVPS、两种可持续 ROE 下的 `V_cb` 与闸门读数 |

粗算口径偏保守：只计货币资金、应收账款（×0.75）、存货（×0.5），减负债合计；交易性金融资产、应收票据与融资、预付和其他流动资产不计，少数股东权益与其他权益工具未扣。市净率取腾讯行情字段，分母口径未逐家核对（是否已扣永续债、优先股），精算时按普通股权益重算。原始下载存于会话临时目录，不入库。
