# 外部审计对照（2026-10-05）

用户贴来 Opus 5.5、Fable 5.1 网页版对 8 只股票的低估判断（格力、招行、平安、中创智领、腾讯、PDD、Adobe、Alphabet）。本目录拆解模型 V，并用 A 股历史检验审计隐含的修正方向。分析报告：`docs/reports/external_audit_comparison_2026-10-05.zh.md`；回测日志 §12.309。

| 文件 | 内容 |
|---|---|
| `preregister.md` | 历史检验预登记（运行前写定） |
| `feature_bias.py` | 现行生产候选侧状态 2010-01 起月末 `P/V` × 1／3 年含分红回报，四个特征（净现金占比 S、TTM 下行 T、g0 = 0 而利润增长 D、高 ROIC0 R）的含特征回归、分桶残差、具名个案与现行池暴露 → `results.json`、`cases.csv`、`pool_exposure.csv`；逐月观测写 `cache/observations.csv`（不入库） |
| `sensitivity.py` | 8 只的模型 V 拆解与单项敏感度 → `sensitivity.json`；审计区间与 09-30 独立估值对照 → `audit_compare.csv` |

```bash
python3 feature_bias.py     # 约 1 分 17 秒，峰值内存 0.7 GB（登录节点）
python3 sensitivity.py
```

## 结果摘要

- 排序：模型与两份审计中值的 Spearman 为 0.12（A 股四只 −0.6，海外四只 0.8）；两份审计之间为 0.90。
- 3 年期 δ（正值 = 模型偏乐观），单独回归，90% 区间按股票重抽 1,000 次：

  | 特征 | 面板 | 全部 ROIC |
  |---|---|---|
  | S | −2.43 [−4.48, −0.62] | −1.40 [−4.13, +1.41] |
  | T | +0.22 [−0.41, +0.78] | −0.42 [−1.99, +0.46] |
  | D | −0.02 [−0.51, +0.61] | +0.56 [−0.27, +1.94] |
  | R | +0.55 [+0.23, +1.01] | +1.02 [+0.55, +1.81] |

  - R 的效应只出现在 2019–23 年起点，2010–18 年系数约 0。
  - 1 年期 `P/V` 斜率约 0，读数不可用。
- 个案：格力 152 个月平均残差 +0.8 个百分点／年，中创智领 107 个月 −8.9（集中在 2011–15 年起点），同力 29 个月 +20.7。
- 行业：2010–14 年起点专用设备 −7.3 个百分点／年、煤炭开采 −25.3，此后转正。
- 现行池暴露：净现金占 V ≥ 0.3 的 19 只，其中买入线内只有格力、青岛啤酒、五粮液；TTM < 0.9 且 λ ≥ 0.5 的 10 只；D = 1 的 18 只，买入线内只有神火、天山铝业。
