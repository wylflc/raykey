# 外部审计对照：模型 P/V 三类疑似偏差的历史检验预登记（2026-10-05 北京时间，运行之前）

## 问题

用户 2026-10-05 贴来两份网页版审计（Opus 5.5、Fable 5.1），对 8 只股票的低估判断与工作流相反处集中在三类：

- 净现金占模型价值比例高的公司（格力、PDD）：模型按账面全额计入，审计按经营负债或不分红打折；
- 盈利下行中的周期股（中创智领）：模型锚取三年中位与 TTM 的 λ 混合，审计按当年盈利；
- 净再投资为负、利润仍在增长的轻资产公司（腾讯、Adobe）：模型资本腿判 g0 = 0，审计按增长给倍数。

本检验问：在 A 股历史上，模型 `P/V` 相同的公司里，带上述特征的公司其后实际回报是否系统偏低（模型偏乐观）或偏高（偏悲观）。只作用户裁定的参考，不改生产。

## 数据

- 观测：现行生产候选侧逐日状态 `data/processed/a_share_daily_states_adopted.csv`，每只每月最后一个交易日的 `valuation_ratio`，2010-01 起；状态所用带取 `data/processed/roic_bands.csv` 同键行（代码、报告期、可得日），只取 `growth`／`zero_growth` 路径的 ok 带，沿用旧带的行（判定同 `exp_oi217f_20260925/fairness.py` 的 `judge`）不进样本；银行与保险剔除。
- 前向回报：1 年与 3 年含现金分红再投的年化总回报（`moat_param_lab.total_return_index`／`forward_annualized`），`y = ln(1 + R)`；行情截至 2026-08-28。
- 主样本 `0.2 ≤ P/V ≤ 5`。两个总体同等地位：面板在册期与全部 ROIC 路径月份。

## 特征（全部取自该带行，不用价格）

| 记号 | 定义 | 疑似偏差 |
| --- | --- | --- |
| `S` | 净金融资产占模型价值：`max(0, −fin_net_debt_ps) ÷ intrinsic_value`，夹 `[0, 1]` | 现金按账面全额计入 |
| `T` | TTM 下行：`max(0, −ln ttm_factor)`，年报行与缺值为 0 | 锚对盈利下行反应不足 |
| `D` | 轻资产增长：`g0 = 0` 且利润增速腿 `g_trailing ≥ 5%` | 资本腿看不见不靠净再投资的增长 |
| `R` | 高回报：`ln(roic0 ÷ 12%)` 夹 `[0, 3]` | 整本回报统一衰减到 12% 对持久高回报过严 |

## 读数

1. **校准**：月固定效应 `y = a_t + b·ln PV`，报 `b`。
2. **含特征回归（主读数）**：`y = a_t + b·ln PV + c·F`，每个特征单独一次、四个一起一次。`δ_F = c ÷ b` 为数据隐含的模型价值对数调整：`δ > 0` 表示带此特征时模型 V 偏高（应调低），`δ < 0` 表示偏低。对 `S`，`δ_S` 约等于净现金应打的折扣比例（1 = 市场其后对这部分现金不付钱）。90% 区间按股票整体重抽 1,000 次的分位数。
3. **分桶残差**：按读数 1 校准后，各特征分桶的平均残差（年化对数回报）与 90% 区间。`S`：[0, 0.1)、[0.1, 0.3)、[0.3, 0.5)、[0.5, 1]；`T`：ttm_factor ≥ 1、[0.9, 1)、[0.8, 0.9)、< 0.8；`D`：是／否；`R`：roic0 < 15%、[15%, 30%)、[30%, 60%)、≥ 60%。
4. **具名**：格力 000651、中创智领 601717、同力 920599 每年 12 月末与最新一月的 P/V、各特征、实际 1／3 年回报、按读数 1 预测的回报。
5. **现行池暴露**：`a_share_pool_model_bands_adopted.csv` 的 ROIC 路径非金融公司，四个特征的分布与名单，配 09-30 扫描 P/V。

## 判定

`δ` 的 90% 区间不含 0、两个总体与 3 年期同号，记「数据支持该方向的调整」，并报点估计幅度；1 年期只作旁证。区间含 0 记「不能区分」。本检验不改任何口径；采纳与否由用户按 §12.1 裁定。

## 已知局限

- 检验的是市场其后的定价加分红，不是现金流本身。市场长期给现金打折（治理、不分红）时，读数会显示「模型高估现金」，这正是持有人实际拿到的回报，但不等于现金的会计价值有误。
- 3 年窗口逐月重叠，推断只用按股票重抽。特征之间、特征与行业之间相关，单独与合并两种回归都报。
- 现行生产状态含 v4.228 之前全部口径修订（后视）；ROIC 路径约 300 只公司，含幸存者偏差。
