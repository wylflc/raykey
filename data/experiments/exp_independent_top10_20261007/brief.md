# P/V 前十独立估值：任务说明与材料索引（2026-10-07）

结论与对照见[报告](../../../docs/reports/independent_low_pv_top10_2026-10-07.zh.md)。本目录只存证据，不改任何口径。

## 任务

用户 2026-10-07 要求：给出当前 `P/V` 最低的前十，逐只做独立于工作流程的分析，判断是否真的低估。

名单取自 `data/processed/daily_buy_candidates.csv`。信号日为 2026-09-30（10-01～10-07 国庆休市），版本为 v4.236 重发后。按候选侧 `model_pv` 升序取前十，共 177 只有效值。

## 独立性约束

每只由一个分析代理完成。代理不读仓库，只用以下材料：

1. `packs/` 数据包与对应原始 JSON（东财 F10 全部报告期三表、主营构成、分红明细，腾讯行情）；
2. 公告原文与公开网络资料；
3. 行业常识。

工作流程、模型带、`P/V`、档案、报告和决策日志都不读。2026 年 6 月以后的事实一律注明来源，查不到就写「未查到」。

## 统一框架

1. 生意与竞争格局。
2. 盈利质量与正常化：现金转换，经调整净现金（扣受限、质押、经营备付、已宣派股利、类债务）。
3. 最新动态：2026 中报、Q3 线索、假期新闻。
4. 三法互校：
   - 所有者收益 DCF：股权成本基准 9%，终值增长 ≤ 2.5%；小市值或强周期可用 10%，须说明；报 8%／10% 敏感性；
   - 反向 DCF；
   - 交叉验证：股息加回购、历史估值、同业、EV/EBIT、AH 比价。
5. 熊／基准／牛概率加权得独立 V。
6. 独立 `P/V` = 现价 ÷ 独立 V，分四档：≤ 0.75 明显低估；0.75～0.90 温和低估；0.90～1.10 大致合理；> 1.10 偏贵或价值陷阱风险高。
7. 3～5 条带数字门槛和时点的证伪条件。

## 材料

| 路径 | 内容 |
| --- | --- |
| `companies/<代码>_<名称>.md` | 逐只分析全文，含来源链接 |
| `packs/<代码>_<名称>.md` | 数据包：快照、TTM、资产负债结构、年度与单季表、主营构成、分红、历史估值 |
| `tools/fetch_all.py` | 东财 F10 全部报告期三表、主营构成、分红 |
| `tools/fetch_prices.py` | 腾讯月线（不复权、后复权）、2026 日线与实时报价 |
| `tools/build_pack.py` | 由原始 JSON 生成数据包 |
