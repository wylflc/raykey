# OI-290 g0 = 0 下限改基准增速——预登记（2026-10-19 北京时间，建带之前）

## 问题

现行 g0 = `min(五年增量 ROIC, 40%) × 再投资率`，资本腿 ≤ 0 或算不出时为 0（工作流 §6.5.1）。增长率假设评估（回测日志 §12.343，[报告](../../../docs/reports/growth_assumption_review_2026-10-19.zh.md)）：
- 10-16 池内 growth 路径 171 只中 52 只 g0 = 0：再投资率 ≤ 0 的 21 只，增量回报 ≤ 0 或算不出的 28 只，主体重置 3 只。
- 回测宇宙内，这两档其后 5 年净利增速中位 6.9%、18.7%，模型隐含约 0.9%；g0 > 0 各档隐含与实际中位相符。

本检验问：资本腿失效时改取基准增速后，(1) 隐含增速是否更接近实际，(2) `P/V` 对其后回报是否更准。用户 2026-10-19 裁定登记并检验；按 §12.1（v4.254）以输入预测力与估值准确性裁定，回测收益读数只报。

## 受影响行（跑数前写定）

候选侧 ROIC `growth` 路径行中，对照臂 g0 = 0 且 `roic_g_source = none` 的行：资本腿不可算或 ≤ 0。主体重置 `growth_mode = none` 的行（`entity_reset_none`）不改。研究增长、存量型上限只在生产执行，本检验不涉及。

## 观测与读数（跑完不换）

月末 `P/V`（2010-01 起）、其后 3 年与 5 年含分红年化回报，同 `exp_oi254_20261005/test.py` 的口径；`0.2 ≤ P/V ≤ 5`；沿用旧带的行不进样本。

1. **输入预测力**：
   - 受影响年报行：各臂隐含 5 年平均增速（10 年线性降到 3% 的前 5 年平均）对其后 5 年净利（两年均值端点）与营收增速，报分档中位偏差与绝对误差中位；
   - 全部 growth 行：各臂 g0 对实际增速的逐年截面秩相关中位。
   - 口径同 `exp_growth_assumption_20261019/tools/growth_predictability.py`。
2. **主读数（受影响行校准）**：
   - 用不受影响的 ROIC 路径非金融公司月份拟合 `y = a_t + b·ln PV`（月固定效应）；
   - 受影响月份在 `C`、`F3`、`F5`、`FR` 下的平均残差（实际 − 预测，年化对数），按股票整体重抽 1,000 次给 90% 区间。
3. **包含检验**：
   - 全样本 `y = a_t + b·ln PV_C + g·d`，`d = ln(PV_臂 ÷ PV_C)`（只在受影响月份非 0），`λ = g ÷ b`；
   - 1 = 调整恰好，0 = 无信息，按股票重抽给 90% 区间。
4. **时期**：2010–2014、2015–2018、2019–2023 起点分报读数 2。
5. **截面排序**：每月全部 ROIC 路径公司 `−ln P/V` 与其后回报的秩相关，各臂对 `C` 的配对差（逐月），报中位与为正月份占比。
6. **机会与陷阱**：§12.1 第 13 款读数，各臂与 `C` 并列。
7. **现值**：10-16 池内受影响成员各臂的 V、`P/V` 与买入区进出（买入线按 §12.1 对齐容差处理）。
8. **回测**：按 §12.1 照报标准起点集参考读数与读数标记，不作依据。

## 判定

- **支持**须同时满足：
  - 读数 2 中该臂平均残差的绝对值小于 `C`，且其 90% 区间含 0 而 `C` 的不含 0；
  - 读数 3 的 λ 区间不含 0；
  - 读数 4 三个时期中至少两个同向；
  - 读数 1 中受影响行的绝对误差小于 `C`。
- 只部分满足的报「部分支持」，写明哪项不满足；都不满足报「不支持」。
- 任何改动按 §12.1 交用户裁定；本批不改生产。

## 已知局限

- 实际增速用归母净利与营收总额，含增发摊薄与非经常损益；g0 指每股 NOPAT。
- 「增量回报 ≤ 0」多是窗口止于低谷，其后反弹部分是利润水平回归；谷底守卫已部分处理利润水平。
- 3／5 年窗口逐月重叠，推断只用按股票重抽。
- `FR` 的收缩系数 0.5 与上限 10% 为跑数前设定，不做扫描。
