# OI-250 登记扩到池内全部 ROIC 路径：判定任务（2026-10-01）

用户 2026-10-01 裁定：业务属性登记（个人投资体系第 5.12 节）从峰守卫生效的 57 只扩到池内全部 ROIC 路径成员。本目录 `inputs.csv` 为尚未登记的 116 只。

口径：`../exp_oi250_pilot_20261001/rubric.md`（v2）。要点：
- 定价方式按利润主导项判；商品价格接受者一律归周期型（成本领先或一般），需求扩张也不例外。
- 需求空间：`结构扩张` 须写明驱动与可证伪的量（未来 3～5 年行业需求年增明显高于名义 GDP）。
- 可复制性按「同业两年内能否扩产并压价」判；仓库「资本复制测试」通过只是必要条件，须另看同业扩产、价格战与毛利率走势（`inputs.csv` 的 `gross_margin_trend`、`revenue_trend` 列来自仓库逐季面板）。代工、组装型利润（毛利率低、议价在客户）判易复制。
- 成本地位只对商品价格接受者判。
- 只用 2026-09-30 及以前可得的信息；依据以仓库研究记录为主，可补充公开常识。
- 已登记 57 只的判定见 `../exp_oi250_pilot_20261001/attributes_v2.csv`，同载体、同业的公司须同判（例如同一产品链上的公司），分歧写在 `note`。

不得改动本目录以外的文件；不得读 `docs/xzy/`。

## 输出

`attributes_part<N>.csv`（UTF-8，逗号分隔，带表头），每只一行，列：

| 列 | 说明 |
| --- | --- |
| `security_code`、`security_name` | 同 `inputs.csv` |
| `pricing_mode` | `商品价格接受者`／`差异化定价` |
| `demand_runway` | `存量`／`结构扩张` |
| `replicability` | `易复制`／`难复制` |
| `replicability_confidence` | 可复制性判定的把握：`高`／`中`／`低` |
| `cost_position` | `领先`／`一般`／`不适用`（差异化定价填 `不适用`） |
| `derived_class` | 按 rubric 派生规则：`价格周期型`／`成本领先周期型`／`结构成长型`／`可复制成长型`／`稳定型` |
| `evidence` | ≤ 120 字，点出所依据的仓库记录或公开事实，带年份；可复制性须提到同业扩产、价格或毛利率证据 |
| `evidence_date` | 依据的最晚可得日，不晚于 2026-09-30 |
| `falsifier` | ≤ 60 字，改判条件，尽量写成可量的指标与阈值 |
| `confidence` | 整体把握：`高`／`中`／`低` |
| `note` | 可空；分歧点、与同业判定的对照 |
