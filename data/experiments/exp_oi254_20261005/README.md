## 判定（按预登记）

- **A1 不支持**：残差几乎不变，现行 `C` 的全期区间本就含 0；λ 区间含 0。
- **A2 部分支持**：包含检验方向获支持，但残差改善小（−3.9 → −3.1），三个时期只有 2010–14 一期改善。
- 2010–2018 年这一类的偏乐观（−10 到 −12 个百分点／年）在整周期锚下基本不变。十年中位本身也覆盖不了 2012–2016 年那样深的下行。差异集中在个股，与 OI-245（§12.296）的结论一致，宜交研究数机制（§6.5.2.2）处理。
