## 判定（按预登记）

- 没有候选的平均绝对误差改善区间不含 0。C5 偏差最大，C4 在两家子样本上显著更差。
- **维持现行 C0**：含 TTM 的净利润锚对其后三年 ROE 的预测与各平滑口径相当，保险内排序最好；平安 2021–2022 年各口径都未预见 ROE 从 20% 降到 12%。
- 现行的代价是摆动较大（月变动 ≥ 10% 的月份占 11.2%，C1 为 6.7%）。若更看重稳定，C1（去 TTM）误差相当、同尺偏差含 0，可作备选，但不满足预登记的改口径前提。
